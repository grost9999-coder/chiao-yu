# 攤商業別與自訂品項

入口：攤位選擇下方的「業別／品項」。原有九個功能分頁保持不變。

每攤可選餐飲、飲料、蔬果生鮮、服飾、雜貨手作、服務或自訂範本。範本僅加入品項選項，所有初始單價為 0，使用者須設定真實價格。套用多次不會重複建立相同類型／名稱／單位的範本品項，不會建立交易或實體庫存。

可新增、編輯、停用及啟用品項。每項記錄類型、分類、名稱、單位、預設數量與每單位價格。銷售、進貨、支出、資產表單可帶入品項；庫存頁可帶入進貨品項名稱、單位與單價，實際庫存從 0 開始，必須盤點確認。加工頁可選用自訂銷售品名。

新銷售紀錄保存當時的單位、數量、價格、金額快照。數量或單價變動才重算合計（四捨五入到小數二位）；合計可手動調整，例如折扣或負數退款。歷史金額仍是收入來源，不會再乘一次數量。進貨價格欄表示本次總金額，與每單位價格分開。不同單位不自動換算。售出商品與原料的配方、庫存扣料關係未在此版本自動建立。

設定保存在 `vb_profiles_v30` 每攤的 `catalog` 欄位，與現有 JSON 備份的 `vendor` 欄位一起匯出。匯入會驗證並合併至目前選定攤商，保留其他攤商；相同編號但不同內容會中止並提示核對，不靜默覆蓋。原有資料表與損益計算不變。

目前仍是裝置本機儲存。帳號註冊與雲端同步尚未實作。GitHub 更新不等於已發佈 TestFlight 或 App Store，仍須使用 Codemagic 建置上傳，再進行 iPhone 實機驗收。

驗證：`node ios/tests/catalog.test.cjs`、既有 profit / inventory / subscription-recovery 回歸測試。涵蓋範本、重複套用、品項驗證、零與小數數量價格、跨攤隔離、停用、歷史金額、設定表單與還原衝突。原生採購、簽章與實機操作仍須 TestFlight 驗證。
