# 上架資料草稿（尚未提交）

名稱：攤商記帳
副標題：出攤收支、庫存與多攤位管理
關鍵字：攤商,記帳,夜市,市集,庫存,營收,成本,備份
主要類別建議：財經；次要類別建議：商業。由帳號持有人確認。

說明：
專為市集、夜市與小攤位日常管理設計，集中記錄每日營收、進貨、固定支出、加工、資產、庫存與備忘。最多設定 20 個攤位名稱，切換查看各自資料，並以分析頁檢視日、周、月、年的紀錄。支援 JSON 備份匯出與匯入。

帳本保存在裝置內，無須註冊帳號。更換裝置、解除安裝前請先匯出備份。本 App 不提供雲端同步；統計結果僅供日常管理參考。

審查備註草稿：
本 App 不需登入。打開後點新增攤商，即可使用各頁記錄帳目。備份／匯入分頁提供 JSON 檔案匯出、原始資料封存及舊版格式轉換。應以乾淨測試資料驗證，提交截圖不得包含真實營業帳目。

待補：支援 URL、隱私政策 URL、版權人、聯絡電話／Email、審查聯絡資訊、實機截圖、價格／地區／分級。
