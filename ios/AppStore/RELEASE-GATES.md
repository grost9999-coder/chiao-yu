# 提交前的驗收與缺口

依用戶決定，改為免註冊、免登入的本機模式。沒有 Firebase 登入、雲端備份或後端部署需求。

| 項目 | 本版內容 | 仍需完成 |
|---|---|---|
| 本機資料 | 沿用持久化 default WebKit 空間；不搬移或清除既有帳本；JSON 匯出與匯入 | 實機更新後核對既有資料、終止重開與逐攤換機還原 |
| 帳號 | 移除登入入口、Firebase SDK、Apple 登入 entitlement 與建置設定檢查 | 無需申請 Firebase 服務或提供登入審查帳號 |
| 訂閱 | Apple StoreKit 控制權益；恢復購買與帳本還原分開；月繳目標 NT$100 | ASC 價格、試用日期／地區與資格、sandbox 購買及恢復驗收 |
| 備份 | 常駐匯出入口；到期仍能匯出；每七天於前景提醒備份 | 分享選單實際儲存與匯入結果核對；各攤需各自備份 |
| iPad | 裝置家族 1、2 與四方向 | 直橫向、鍵盤、照片、彈窗確認與取消實機驗收 |
| 展示 | DEBUG 隔離資料與原生錄影流程 | 先前原生錄影失敗，修復並逐段審視；無 Duo runtime 時待補 |
| 送審 | 本機版產品文案、政策與支援頁原始碼 | 發布頁面、填電話、隱私問卷／分級／分類／地區／合規、選新建置 |

## 隱私與文案
不要求 App 帳號；帳本與原始照片不自動傳到開發者伺服器。照片在裝置辨識，備份包含文字與配方、不包含原始照片。使用者自行選擇 iCloud Drive 等儲存位置時，由該服務處理檔案。隱私問卷仍應依正式 binary 和實際 StoreKit 處理核對，不能只依文案作答。

不宣稱恢復購買能恢復帳本、不宣稱加工自動扣除全部庫存、不對所有用戶承諾首月免費。

## 發布狀態
程式提交至修正分支，未合併、未更新 App Store Connect 或 TestFlight。正式 IPA 仍由 Codemagic 建置、簽章及上傳；不需要 FIREBASE_IOS_CONFIG_BASE64。
